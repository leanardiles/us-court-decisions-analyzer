1. Where the project stands

Capstone II tests whether a multi-agent reading layer catches incorrect answers on election-law opinions better than a single model call plus self-reported confidence — without replacing the human scholar as the final authority.

This week’s snapshot. The full LEXIS corpus is now in a shared Postgres database, identified by citation (not file name), grouped into litigation families, and searchable with vector retrieval. The evaluation set is a frozen 50-decision pilot. We have not yet run System A vs System B or written the Q1/Q2 answer key. That is the work of the next several weeks.

This updates the 23–24 September plan (then a 20-case Parquet file in the Capstone I app). Filenames such as Craig v. Simon (2) are other decisions in the same lawsuit (often district vs. appellate), not duplicates. Identity is the U.S. LEXIS citation. The corpus lives in shared Postgres (Supabase), not Capstone I SQLite. The Capstone I application remains the System A baseline (single Groq call, human-in-the-loop). It is not the corpus of record.

2. Research question (unchanged)

On the same frozen opinions and the same two questions, does System B (two independent readers + an adjudicator that preserves disagreement) outperform System A (one Groq call, Capstone I style) — especially on the temporal question Capstone I failed?

QuestionRole in the experiment
Q1 — type of electionControl. Capstone I was already strong here.
Q2 — days between the trial ruling and the electionKnown failure mode (temporal / Purcell-style reasoning).

Metrics remain accuracy vs. human labels, disagreement among agents, calibration, tokens, latency, and cost. Agents flag; validators and the scholar still decide. We are not building a chatbot for litigants.

4. How the pieces fit

Ingest is rule-based (no LLM). Embeddings are a small local model. Groq is reserved for the experiment. On the 50, a reader can still receive the full opinion. Retrieval is for the other ~490 longer opinions and for later evidence checking (an agent cites a character span; we verify it is actually in the opinion).

7. Risks we are watching

  • Labels are the gate. We cannot score either system until Q1/Q2 ground truth exists for the frozen 50. Poor-fit cases get a new manifest version, not a silent regenerate.
  • Nine of the 50 have no U.S. LEXIS citation (often state-court exports). Those rows are keyed by source filename.
  • Groq cost. Ingest did not use Groq; agent runs will. We will log tokens and cost. We are not sending all 540 full opinions through an LLM.

1. One-sentence status

The court-opinion corpus is ingested into one shared Supabase Postgres database, identified by LEXIS citation (not file name), grouped into litigation families, chunked, and searchable with pgvector. Enock’s track is the RAG retrieve store. Alex’s track starts here: generate answers with Groq agents using this data. Do not rebuild ingest. Do not use the Capstone I SQLite app as the corpus.

3. How to think about the data (Leandro’s rules)

  • Unit of identity: LEXIS citation, e.g. 2020 U.S. Dist. LEXIS 187996.
  • Craig v. Simon.docx and Craig v. Simon(2).docx are different decisions (8th Cir. vs D. Minn.), same family.
  • Do not collapse filenames. Do not key experiments on short_name alone.
  • About 86 files have no U.S. … LEXIS line (often state courts) — lexis_citation is null; they still have source_filename.
  • One true re-export pair shares 2021 U.S. LEXIS 1197 (two captions, one cite). Only one row was loaded.

9. Appendix — connect, SQL, retrieve contract

Read this before the first agent run. Passwords stay out of this file; Enock sends them privately.

9.1 Connect (session pooler, not the “direct” host)

db.mvpecqzqzuuxpwuazyaq.supabase.co:5432 does not resolve on a typical IPv4 laptop. Use:

  • Host aws-0-us-east-2.pooler.supabase.com · port 6543 · db postgres
  • User postgres.mvpecqzqzuuxpwuazyaq · SSL required
  • SUPABASE_URL=https://mvpecqzqzuuxpwuazyaq.supabase.co
  • SUPABASE_DB_PASSWORD='…' — single-quote it (# and $)
  • SUPABASE_DB_URL = same user @ pooler host, URL-encoded password, ?sslmode=require

9.2 Embedding contract (must match)

  • Model BAAI/bge-small-en-v1.5 · 384-d · local fastembed
  • Distance cosine · Postgres <=>
  • Chunks ~3200 chars / 400 overlap · section = opinion | dissent | concur
  • Query prefix is already applied in embed_query()
  • First run downloads the model from Hugging Face (no token)
The publishable sb_publishable_… key cannot REST-query these tables (“Secret API key required”). Use Postgres (password / pooler), not supabase-js + anon, until RLS is added.

9.3 SQL Alex will actually run

-- one decision; if lexis_citation is null, key by source_filename select lexis_citation, source_filename, court, decision_date, opinion_text, dissent_text from decisions where lexis_citation = '2020 U.S. Dist. LEXIS 187996'; select * from decisions where source_filename = 'Abdus-Sabur v. Evans.docx'; -- siblings in the same lawsuit select d.short_name, d.lexis_citation, d.court_level, d.decision_date, d.source_filename from decisions d join litigation_families f on f.id = d.family_id where f.family_key = 'craig v simon' order by d.decision_date;

Pilot 50: backend/data/pilot_50_manifest.json. About 9 of 50 have no U.S. LEXIS cite — key those by source_filename. Chosen as 2k–50k chars, max 3 per family. Full opinion text is stored (the length cap was only for picking the 50).

9.4 Python retrieve (returns dicts; CLI still prints)

9.5 Experiment log (JSONL now, agent_runs table later)

One object per agent call: lexis_citation or source_filename, system (A|B), agent_role (reader_a|reader_b|adjudicator), model, prompt_version, question_id (Q1|Q2), answer, cited_char_start, cited_char_end, confidence, agree, tokens_in, tokens_out, latency_ms, cost_usd, run_at. Do not write these into decisions.opinion_text.
